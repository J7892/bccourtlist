Court List Legend & Column Meanings

Definitions based on the official BC Ministry of Attorney General Criminal Court Lists guide:

Common Columns
  • Rm: Courtroom number
  • File Number: Court file registry number
  • Proc (Bail Process): Bail status (WAR = Warrant, UTP = Undertaking, SUM = Summons)
  • I/C: In Custody status (Y = In Custody, N = Out of Custody)
  • Cnt: Count / charge sequence number
  • Rsn: Purpose/Reason (FA = First Appearance, PAR = Pre-Trial, SNT = Sentence)
Outcomes & Results
  • Rslt: IBJ = In Between Judgment / Adjourned, END = Concluded
  • Disposition: Final result: SOP = Stay of Proceedings, APG = Admitted Guilty, PNI = Not Guilty plea
  • V/C: By Videoconference (CON = Video link, ACC = Accused on video)
  • Agency File: Police agency code and investigation incident number
